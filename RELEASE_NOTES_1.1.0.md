## 2. Назначение установочных пакетов (APK)
* **app-universal-release.apk**: Универсальная сборка. Содержит нативные библиотеки под все архитектуры (ARM64, ARMv7, x86, x86_64). Гарантированно подходит для любого Android-устройства. Единый основной файл для автообновлений и публикации.
* **app-arm64-v8a-release.apk**: Сборка ARM64. Оптимизирована для большинства современных смартфонов и планшетов (64-битные процессоры ARM). Обладает меньшим размером.
* **app-armeabi-v7a-release.apk**: Сборка ARMv7. Для старых 32-битных Android-устройств.
* **app-x86_64-release.apk**: Сборка x86_64. Для 64-битных эмуляторов Android (Android Studio, LDPlayer, BlueStacks) и устройств на базах процессоров Intel/AMD.
* **app-x86-release.apk**: Сборка x86. Для 32-битных эмуляторов Android x86.

## 3. Ключевые изменения

### Оптимизация сборки и производительность (R8 & Baseline Profiles)
* **Агрессивная оптимизация байткода (R8 / ProGuard)**:
  * Настроена конфигурация правил R8 (`-optimizations`) для глубокого сжатия и минификации кода без нарушения работоспособности JNI и криптографии.
  * Устранена генерация неиспользуемых метаданных библиотеки Kotlin.
* **Профили предварительной компиляции (Baseline Profiles)**:
  * Добавлен файл `baseline-prof.txt` для ускорения AOT-компиляции ART на стороне системы. Снижено время холодного запуска приложения.
* **Сокращение размера пакетов**:
  * Размер универсальной сборки оптимизирован до ~7.1 МБ, а сборки `arm64-v8a` — до ~4.8 МБ.

### Сетевой стек и обработка протоколов (MTProto & SOCKS5)
* **Низкоуровневая оптимизация буферов (`MsgSplitter`, `TgWsBridge`, `Socks5WsBridge`)**:
  * Реализована прямая обработка срезов байтовых массивов по оффсету и длине без лишних аллокаций `ByteArray` при разделении пакетов frame-уровня.
  * Ликвидированы фрагментации памяти и частые вызовы Garbage Collector при высокоскоростной передаче файлов.
* **Устойчивость пула веб-сокетов (`WsPool`)**:
  * В область корутин пула `WsPool` встроен `SupervisorJob()`. Ошибка отдельной корутины восполнения соединений больше не отменяет работу родительского контекста.
* **Корректность состояний `LocalProxyServer`**:
  * Синхронизирован статус `isNativeRunning` в режиме SOCKS5 для предотвращения фиктивных вызовов нативных библиотек.

### Фоновые процессы и UI-слой
* **Потокобезопасный `AppLogger`**:
  * Логирование переведено на асинхронный кольцевой буфер, исключающий блокировку потока обработки сообщений при непрерывной записи событий.
* **Устранение утечек подписок в Jetpack Compose**:
  * Все подписки на `StateFlow` и каналы сетевой аналитики увязаны с `DisposableEffect` и корректным циклом жизни экранов (`HomeScreen`, `HistoryScreen`, `LogsScreen`, `UpdateDialog`).
* **Оптимизация рендеринга `CyberEnergyCanvas`**:
  * Анимация фонового холста автоматически приостанавливается, когда экран не активен или находится в фоновом режиме, сохраняя ресурсы GPU и заряд аккумулятора.

### Система обновлений (`UpdateChecker` & `UpdateManager`)
* **Парсинг версий и артефактов**:
  * Доработан метод `cleanVersionString` для извлечения чистых версий формата `X.Y.Z` и предотвращения сбоев сравнения номеров релиза.
  * Добавлен алгоритм выбора `app-universal-release.apk` в качестве приоритетного артефакта обновления.
  * Устранены лишние HTTP-запросы за счет очистки кеша ETag при ручной проверке обновлений.
