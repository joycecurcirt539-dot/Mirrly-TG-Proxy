## 2. Назначение установочных пакетов (APK)
* **app-universal-release.apk**: Универсальная сборка. Содержит нативные библиотеки под все архитектуры (ARM64, ARMv7, x86, x86_64). Гарантированно подходит для любого Android-устройства. Единый основной файл для автообновлений и публикации.
* **app-arm64-v8a-release.apk**: Сборка ARM64. Оптимизирована для большинства современных смартфонов и планшетов (64-битные процессоры ARM). Обладает наименьшим размером.
* **app-armeabi-v7a-release.apk**: Сборка ARMv7. Для старых 32-битных Android-устройств.
* **app-x86_64-release.apk**: Сборка x86_64. Для 64-битных эмуляторов Android (Android Studio, LDPlayer, BlueStacks) и устройств на базе процессоров Intel/AMD.
* **app-x86-release.apk**: Сборка x86. Для 32-битных эмуляторов Android x86.

## 3. Ключевые изменения

### Сканирование и быстрый импорт QR-кодов
* **Интеграция движка Google ML Kit Barcode Scanning**:
  * Сканер приложения переведен на передовую нейросетевую модель машинного зрения Google ML Kit (технология Google Lens).
  * Обеспечено мгновенное аппаратное распознавание QR-кодов под любыми углами, наклонами, при слабом освещении и на любых типах экранов.
  * Добавлена встроенная поддержка как светлых, так и инвертированных темных QR-кодов (из консоли Windows/PowerShell).
* **Секция сканера в Менеджере воркеров**:
  * Реализован полноэкранный интерфейс камеры на базе CameraX с анимированной лазерной сеткой видоискателя.
  * Добавлено управление фонариком (вспышкой) с использованием векторных иконок (`ic_flash_on.xml`, `ic_flash_off.xml`).
  * Добавлена кнопка мгновенного вызова сканера «QR» прямо из панели фильтрации воркеров.
  * Интегрирована кнопка ручной вставки адреса из буфера обмена.

### Генератор QR-кодов и обмен узлами
* **Вкладка «Поделиться воркером»**:
  * Реализована генерация персонализированных QR-кодов в стиле AMOLED Liquid Glass с логотипом приложения по центру.
  * Формирование глубоких ссылок `mirrly://worker?domain=...&name=...` для быстрого автоматического импорта узла на других устройствах в один клик.
  * Добавлена быстрая отправка ссылки через системный диалог Android `ACTION_SEND` и копирование адреса узла.
* **Защита узлов разработчика**:
  * Делиться разрешено только личными узлами пользователя (`customWorkers`). Официальные воркеры разработчика защищены от передачи и скрыты из вкладки шаринга.

### Оптимизация размера APK и интерфейс
* **Двукратная оптимизация веса APK**:
  * Использован тонкий клиент `play-services-mlkit-barcode-scanning` без утяжеления установочного файла сторонними C++ библиотеками.
  * Размер универсального релиза сокращен до **13.77 МБ**, а ARM64 — до **4.43 МБ**.
* **Овальный прозрачный дизайн элементов управления**:
  * Возвращен полностью прозрачный фон (`Color.Transparent`) и форма вытянутого овала (`RoundedCornerShape(17.dp)`) для чипов фильтрации (`SegmentedFilterChip`) и кнопок действий.
  * Счетчики узлов переведены в аккуратный встроенный текст без лишних визуальных рамок.

### Инструменты деплоя (`deploy.bat` / `deploy.ps1`)
* **Отображение QR-кода в терминале**:
  * По окончании деплоя в окне консоли выводится компактный квадратный QR-код для моментального сканирования камерой смартфона.
  * Реализован корректный алгоритм чередования блоков Рида-Соломона (уровень `L`), устраняющий искажения и разрывы кода для доменов любой длины.
  * Скрипт сохранен с меткой UTF-8 BOM для полной совместимости со стандартным Windows PowerShell 5.1.
