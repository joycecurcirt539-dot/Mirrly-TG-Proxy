## 2. Назначение установочных пакетов (APK)
* **app-universal-release.apk**: Универсальная сборка. Содержит нативные библиотеки под все архитектуры (ARM64, ARMv7, x86, x86_64). Гарантированно подходит для любого Android-устройства. Единый основной файл для автообновлений и публикации.
* **app-arm64-v8a-release.apk**: Сборка ARM64. Оптимизирована для большинства современных смартфонов и планшетов (64-битные процессоры ARM). Обладает меньшим размером.
* **app-armeabi-v7a-release.apk**: Сборка ARMv7. Для старых 32-битных Android-устройств.
* **app-x86_64-release.apk**: Сборка x86_64. Для 64-битных эмуляторов Android (Android Studio, LDPlayer, BlueStacks) и устройств на базах процессоров Intel/AMD.
* **app-x86-release.apk**: Сборка x86. Для 32-битных эмуляторов Android x86.

## 3. Ключевые изменения

### Локализация и документация
* **Персидская локализация (Farsi)**:
  * Добавлен персидский язык интерфейса (`fa`) с полной поддержкой 1877 строковых ресурсов и RTL-адаптацией.
  * Создана полная документация `README_FA.md` с описанием архитектуры, протоколов MTProto/SOCKS5 и инструкциями по настройке Cloudflare Worker.
  * В главное меню добавлен выбор персидского языка в мастере первого запуска (`OnboardingScreen`) и системных настройках (`SettingsScreen`).

### Интерфейс и тестирование скорости
* **Адаптивное масштабирование индикатора качества**:
  * Внедрено динамическое масштабирование размера шрифта (от 6.4 sp до 11.5 sp) в круговом индикаторе качества канала (`CompactSpeedTestResult`).
  * Длинные текстовые градации качества («Удовлетворительно») центрируются без переноса строк и без выхода за границы круга.
* **Компактная динамика скорости**:
  * Сокращен заголовок графика до «ДИНАМИКА СКОРОСТИ» во всех языковых локалях.
  * Индикатор пиковой скорости выделен в отдельный компактный блок со строгим ограничением по ширине, предотвращая перенос и наложение элементов.

### Безопасность и ограничение системного VPN
* **Изоляция незавершенного VPN-режима**:
  * Добавлена полупрозрачная информационная карточка о нахождении системного VPN в активной разработке.
  * Кнопка питания на главном экране во вкладке VPN заблокирована от запуска системного сервиса и вызывает информационное предупреждение.
  * В настройках протоколов интерактивные тумблеры VPN заменены на уведомление о продолжении инженерных тестов.
