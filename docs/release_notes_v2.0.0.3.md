## 2. Назначение установочных пакетов (APK)
* **app-universal-release.apk**: Универсальная сборка. Содержит нативные библиотеки под все архитектуры (ARM64, ARMv7, x86, x86_64). Гарантированно подходит для любого Android-устройства. Единый основной файл для автообновлений и публикации.
* **app-arm64-v8a-release.apk**: Сборка ARM64. Оптимизирована для большинства современных смартфонов и планшетов (64-битные процессоры ARM). Обладает меньшим размером.
* **app-armeabi-v7a-release.apk**: Сборка ARMv7. Для старых 32-битных Android-устройств.
* **app-x86_64-release.apk**: Сборка x86_64. Для 64-битных эмуляторов Android (Android Studio, LDPlayer, BlueStacks) и устройств на базах процессоров Intel/AMD.
* **app-x86-release.apk**: Сборка x86. Для 32-битных эмуляторов Android x86.

## 3. Ключевые изменения

### Подключение и авторизация Cloudflare
* **Авторизация во встроенной вкладке**: вход в аккаунт Cloudflare теперь открывается прямо внутри приложения через Custom Tabs без переключения в сторонний браузер.
* **Надежный возврат в приложение**: после подтверждения входа браузер автоматически и гарантированно возвращает вас обратно в приложение.
* **Работа в режиме энергосбережения**: предотвращен обрыв авторизации при низком заряде батареи и увеличен таймаут ожидания на медленном мобильном интернете.

### Интерфейс и понятный язык
* **Простые термины и подсказки**: сложные технические слова заменены на простые и понятные формулировки, добавлены поясняющие сноски в диалогах подключения и диагностики.
* **Компактная история подключений**: карточки сессий стали меньше, аккуратнее и показывают только полезную информацию (время, протокол и переданный объем данных).
* **Удобный просмотр логов**: экран записей событий стал компактнее, убраны лишние отступы и шум.
* **Обновленная вкладка «Поделиться»**: карточки воркеров приведены к единому прозрачному стилю, QR-код легко считывается камерой.
* **Названия языков**: в меню выбора добавлены понятные международные обозначения языков.

### Скорость и мобильный интернет
* **Быстрая отправка сообщений и медиа**: устранена задержка при отправке сообщений в MTProto, ускорен предварительный прогрев серверов медиафайлов.
* **Стабильность в мобильных сетях**: улучшен выбор рабочих узлов при нестабильном 3G/LTE/5G, исключены ложные разрывы связи при смене вышек.
* **Быстрое переключение сетей**: прокси мгновенно освобождает порты и переподключается при смене Wi-Fi на мобильную сеть без зависаний.

### Исправления ошибок
* **Первый запуск на Samsung и Huawei**: устранено зависание приветственного экрана и выбора языка на устройствах с оболочками One UI и EMUI/HarmonyOS.
* **Чистка сетевых записей**: удалены дублирующиеся строки проверки DNS и подключений в системных логах.

### Сообщество
* **Зал Славы**: добавлен `creeepeeer` за помощь в тестировании и диагностике стабильности в мобильных сетях LTE/5G.
