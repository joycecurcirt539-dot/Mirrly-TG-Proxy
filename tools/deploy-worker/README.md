# ⚡ Mirrly TG Proxy — Автоматический деплой Cloudflare Worker

Интерактивный комбайн для мгновенного создания и массового деплоя персональных Cloudflare Worker под Telegram MTProto, SOCKS5 и голосовые вызовы VoIP.

---

## 🚀 Способы запуска

### 1. Двойной клик на Windows (через `deploy.bat`)
Просто скачайте папку и дважды кликните по файлу **`deploy.bat`**.

### 2. Запуск через PowerShell (Windows)
```powershell
.\deploy.ps1
```

### 3. Запуск одной строкой без скачивания (PowerShell)
```powershell
irm https://raw.githubusercontent.com/joycecurcirt539-dot/Mirrly-TG-Proxy/main/tools/deploy-worker/deploy.ps1 | iex
```

### 4. Запуск на Linux / macOS / WSL (Bash)
```bash
chmod +x deploy.sh
./deploy.sh
```

---

## 🧠 Возможности и фичи скрипта

* **Красивое интерактивное меню**:
  * `[1]` Быстрое создание воркера с рандомным именем в 1 клик.
  * `[2]` Создание воркера с кастомным именем.
  * `[3]` **Смена аккаунта Cloudflare**: сброс сессии и вход под другой почтой для обхода суточных лимитов 100 000 запросов на бесплатном тарифе.
  * `[4]` **История созданных воркеров**: просмотр всех ваших сгенерированных узлов.
* **Автосохранение в `my_workers.txt`**: скрипт автоматически сохраняет дату, имя, публичный домен и прямую ссылку `mirrly://` каждого созданного воркера.
* **Автоматическое копирование**: публичный домен сразу помещается в буфер обмена системы.
* **100% Автономность**: JS-код воркера со всеми правилами безопасности и API `cloudflare:sockets` уже вшит внутрь скрипта.
* **Проверка зависимостей**: при отсутствии Node.js скрипт предложит открыть официальный сайт для установки в 1 клик.

## 📱 Привязка к приложению:
1. Откройте **Mirrly TG Proxy** → **Менеджер воркеров**.
2. Нажмите **«+ Добавить»** → Вставьте скопированный домен → **«Сохранить»**.
3. Нажмите на добавленный воркер для его мгновенной активации.
