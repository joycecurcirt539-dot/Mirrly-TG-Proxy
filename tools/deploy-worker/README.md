# ⚡ Mirrly TG Proxy — Автоматический деплой Cloudflare Worker

Один автономный скрипт для мгновенного создания и деплоя персонального Cloudflare Worker под Telegram MTProto, SOCKS5 и голосовые вызовы VoIP.

---

## 🚀 Быстрый запуск (Windows PowerShell)

Скачайте и запустите один файл:

```powershell
.\deploy.ps1
```

> Или запуск одной строкой без предварительного скачивания (после публикации на GitHub):
> ```powershell
> irm https://raw.githubusercontent.com/<user>/Mirrly-TG-Proxy/main/tools/deploy-worker/deploy.ps1 | iex
> ```

---

## 🐧 Быстрый запуск (Linux / macOS / WSL)

```bash
chmod +x deploy.sh
./deploy.sh
```

---

## 🛠 Что делает скрипт:
1. Содержит внутри себя **полный JS-код воркера** со всеми подсетями Telegram, allowlist портов и защитой от open-relay.
2. Генерирует уникальное имя воркера (`mtg-relay-xxxxxx`).
3. Открывает браузер для авторизации через официальный OAuth Cloudflare (никаких ручных токенов и ключей API).
4. Автоматически публикует воркер на вашем аккаунте.
5. Выводит готовый домен `xxxx.workers.dev` и **сразу копирует его в буфер обмена**.
6. Полностью удаляет все временные файлы после завершения.

---

## 📱 Привязка к приложению:
1. Откройте **Mirrly TG Proxy** → **Менеджер воркеров**.
2. Нажмите **«+ Добавить»** → Вставьте скопированный домен → **«Сохранить»**.
3. Нажмите на добавленный воркер для его мгновенной активации.
