## 2. Назначение установочных пакетов (APK)
* **app-universal-release.apk**: Универсальная сборка. Содержит нативные библиотеки под все архитектуры (ARM64, ARMv7, x86, x86_64). Гарантированно подходит для любого Android-устройства. Единый основной файл для автообновлений и публикации.
* **app-arm64-v8a-release.apk**: Сборка ARM64. Оптимизирована для большинства современных смартфонов и планшетов (64-битные процессоры ARM). Обладает наименьшим размером.
* **app-armeabi-v7a-release.apk**: Сборка ARMv7. Для более старых 32-битных Android-устройств.
* **app-x86_64-release.apk**: Сборка x86_64. Для 64-битных эмуляторов Android (Android Studio, LDPlayer, BlueStacks) и устройств на процессорах Intel/AMD.
* **app-x86-release.apk**: Сборка x86. Для 32-битных эмуляторов Android x86.

## 3. Ключевые изменения

### Протоколы и нативное Rust-ядро (`mirrlyengine`)
* **Конкурентная гонка воркеров (Happy Eyeballs Race)**:
  * Для режима `MTProto` с включенной опцией туннелирования через воркеры реализован параллельный конкурентный опрос пула узлов со ступенчатой задержкой (100 мс) и контролем параллелизма через семафор.
  * Побеждает первый ответивший узел с наименьшим сетевым RTT; проигравшие WebSocket-соединения автоматически закрываются в фоне.
  * Добавлен автоматический кулдаун для узлов с ответом `HTTP 429 Too Many Requests`.
* **Очистка сетевого конвейера и оптимизация задержек**:
  * Полностью удален модуль сегментации `MsgSplitter` из конвейера `bridge_ws`, что снизило задержки, исключило лишние аллокации памяти и устранило просадки скорости при передаче медиафайлов.
  * Выделен централизованный хелпер маршрутизации IP-адресов дата-центров Telegram (`get_dc_target_ip`) с разделением медиа и сигнальных потоков (DC 1–5, DC 203).

### Архитектура переключения протоколов
* **Менеджер переключения (`ProtocolSwitchManager`)**:
  * Реализована 3-фазная оркестровка переключения режимов (`DISCONNECTING` -> `SWITCHING_ACCENT` -> `RECONNECTING`).
  * Обеспечено корректное плавное завершение активных соединений (spin-down), смена цветового акцента темы оформления и безопасный перезапуск службы без конфликта портов и сокетов.
  * Встроен механизм защиты от спама и дребезга (debounce lock) при повторных нажатиях.

### Интерфейс и жестовая навигация
* **Интерактивный капсульный переключатель (Segmented Capsule Switch)**:
  * На главном экране добавлен переключатель протоколов с поддержкой горизонтальных свайпов (Drag Gestures), пружинной анимацией (`Spring.DampingRatioLowBouncy`) и скользящей неоновой капсулой.
  * Добавлен анимированный бейдж с именем активного воркера при выборе `SOCKS5`.
* **Свайпы и жесты закрытия экранов**:
  * В «Менеджере воркеров» и «Инструкции Cloudflare Worker» добавлена поддержка горизонтальных свайпов для переключения вкладок/фильтров («Все», «Разработчик», «Пользовательские»).
  * Реализован вертикальный жест закрытия экранов с инерционной привязкой к `NestedScroll` и виброоткликом.
* **Обновленный диалог импорта (`ImportWorkerDialog`)**:
  * Диалог импорта по ссылке вынесен в отдельный компонент в стиле полупрозрачного стекла (Frosted Glass) с аппаратным размытием фона (`FLAG_BLUR_BEHIND`) и очищен от эмодзи.

### Настройки и конфигурация
* **Режим скорости по умолчанию**:
  * Пресет скорости по умолчанию переведен в режим `AUTO` (`SpeedPreset.AUTO`) для адаптивной настройки параметров `TCP_NODELAY` под текущие сетевые условия.
* **Упрощение параметров маршрутизации**:
  * Удален устаревший переключатель «Воркер по умолчанию (SOCKS5)»; выбор узла разработчика теперь активируется автоматически при отсутствии пользовательских воркеров.
