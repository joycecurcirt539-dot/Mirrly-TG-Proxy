# Кодекс поведения / Code of Conduct

Этот проект следует принципам "Contributor Covenant" (версия 2.1). Мы стремимся обеспечить дружелюбную, уважительную и продуктивную среду для всех участников.

Если вы участвуете в проекте Mirrly TG Proxy, пожалуйста, уважайте других и придерживайтесь базовых правил вежливости.

Контакт для жалоб и инцидентов / Report Contact
- Для жалоб и сообщений о нарушениях напишите на: rbmkagressive@gmail.com
- Мы постараемся ответить в течение 7 дней.
- Для вопросов, связанных с безопасностью, используйте .github/SECURITY.md или GitHub Security Advisories: https://github.com/joycecurcirt539-dot/Mirrly-TG-Proxy/security/advisories

## Правила поведения / Standards
Примеры неприемлемого поведения включают (но не ограничиваются):
- Агрессивная или унижающая речь, оскорбления и личные нападки.
- Дискриминация по признакам пола, расы, национальности, вероисповедания, ориентации, инвалидности и т.д.
- Публичное раскрытие приватной информации (doxxing).
- Троллинг, домогательства, преследование.
- Нецензурное или чрезмерно грубое поведение.

Мы ожидаем, что все участники:
- Ведут себя уважительно и профессионально.
- Принимают конструктивную критику и отвечают вежливо.
- Стремятся к ясной и доброжелательной коммуникации в issues, PR и обсуждениях.

## Обязательства поддерживающих / Maintainer responsibilities
Люди, которые имеют права на модерацию (мейнтейнеры), обязуются:
- Быть отзывчивыми и внимательными к сообщениям и жалобам.
- Помогать создать безопасную и дружелюбную среду.
- Применять последовательные и прозрачные меры при нарушениях.
- Действовать в интересах сообщества и проекта.

## Процесс рассмотра жалоб / Enforcement
- Если вы столкнулись с проблемой — пожалуйста, сообщите по адресу rbmkagressive@gmail.com или используйте GitHub Security Advisory для чувствительных случаев.
- Мейнтейнеры рассмотрят сообщение и при необходимости свяжутся с вами для уточнений.
- В зависимости от серьёзности инцидента меры могут включать: предупреждение, временное/постоянное блокирование доступа к репозиторию, удаление сообщений или эскалацию на платформу GitHub.

## Применение / Scope
Кодекс поведения применяется ко всем взаимодействиям в контексте проекта: issues, pull requests, discussions, релизы, мероприятия, а также к каналам общения, связанным с проектом (форумы, чаты и т.д.).

# Code of Conduct (English)

This project follows the Contributor Covenant v2.1. We aim to provide a welcoming, respectful, and productive environment for all contributors.

Report Contact
- To report incidents or violations, please contact: rbmkagressive@gmail.com
- We aim to respond within 7 days.
- For security-related reports, see .github/SECURITY.md or use GitHub Security Advisories: https://github.com/joycecurcirt539-dot/Mirrly-TG-Proxy/security/advisories

Standards
Unacceptable behavior includes (but is not limited to):
- Harassment, abusive language, personal attacks.
- Discrimination based on gender, race, nationality, religion, sexual orientation, disability, etc.
- Public disclosure of private information (doxxing).
- Trolling, stalking, or sustained disruption of project communication.
- Excessive profanity or hostile behavior.

Expectations
All contributors are expected to:
- Be respectful and professional.
- Accept constructive criticism graciously.
- Communicate clearly and kindly in issues, PRs and discussions.

Maintainer Responsibilities
Project maintainers will:
- Be responsive and considerate when incidents are reported.
- Help foster a safe and welcoming community.
- Apply consistent, transparent enforcement when necessary.

Enforcement
- Please report issues to rbmkagressive@gmail.com or via GitHub Security Advisory for sensitive cases.
- Maintainers will investigate and follow up as needed.
- Possible actions: warning, temporary or permanent removal of access, content removal, or escalation to GitHub.

Scope
This Code of Conduct applies to all project-related spaces: issues, pull requests, discussions, releases, events, and community channels.
