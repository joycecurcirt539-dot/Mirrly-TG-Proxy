# CONTRIBUTING — Вклад в Mirrly TG Proxy

Спасибо за интерес к вкоду в Mirrly TG Proxy! Ниже — краткое руководство, как быстро начать вносить изменения, оформлять PR и взаимодействовать с проектом.

1) Быстрая подготовка (локально)
- Клонирование:
  git clone https://github.com/joycecurcirt539-dot/Mirrly-TG-Proxy.git
  cd Mirrly-TG-Proxy
- Требования для сборки:
  - JDK 17+
  - Android SDK (API 34, Build-Tools 34.0.0)
  - Android NDK (25+), если вы будете менять нативную часть
- Сборка и тесты:
  - Собрать debug: ./gradlew assembleDebug
  - Собрать релиз (локально): ./gradlew assembleRelease
  - Запустить юнит-тесты: ./gradlew test

2) Стиль кода и проверки
- Kotlin/Compose: придерживайтесь общепринятых практик Kotlin (используйте KtLint/Detekt при необходимости).
- NDK/C++: соблюдайте безопасные практики работы с памятью; избегайте UB и проверяйте границы буферов.
- Пожалуйста, добавляйте/обновляйте unit‑тесты для новой логики.

3) Работа с ветками и коммитами
- Используйте понятные имена веток: feature/<короткое-описание>, fix/<короткое-описание>, docs/<что‑обновлено>.
- Коммиты по возможности мелкие и атомарные. Формат сообщения — по образцу Conventional Commits (рекомендуется):
  - feat: добавляет новую функцию
  - fix: исправляет баг
  - chore: вспомогательные изменения
  - docs: документация
- В описании PR указывайте, какие файлы/модули затронуты, как тестировать изменения и ссылки на связанные issues.

4) Pull Request — чеклист (пример)
- [ ] Описано назначение PR в заголовке и описании
- [ ] Добавлены/обновлены тесты (если применимо)
- [ ] CI проходит (если применимо)
- [ ] Документация обновлена (README / docs)
- [ ] Код соответствует стилю и не содержит явных секретов
- [ ] Подтверждение совместимости с GPLv3 (если вы вносите стороннюю библиотеку, укажите лицензию)

5) Ревью и слияние
- PR будет просматривать мейнтейнер; ожидайте комментарии и правки.
- Мерж производится после прохождения CI и одобрения ревьюверов.

6) Безопасность и приватность
- Не публикуйте приватные ключи/секреты (Cloudflare API keys, личные токены и т.п.).
- Для развёртывания Cloudflare Worker используйте инструкции в docs/cloudflare_worker.js и в README.

7) Лицензирование
- Весь проект распространяется под GPLv3. Отправляя PR вы подтверждаете, что имеете право вносить эти изменения и что ваш вклад может быть опубликован под GPLv3.

8) Вопросы и помощь
- Для общих вопросов используйте Issues: https://github.com/joycecurcirt539-dot/Mirrly-TG-Proxy/issues
- Для сообщений об уязвимостях см. .github/SECURITY.md

Спасибо за вклад! Если нужна помощь с локальной средой — напишите issue с тегом "help wanted" и мы поможем.
