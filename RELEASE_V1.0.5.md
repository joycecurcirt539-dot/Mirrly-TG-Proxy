# Mirrly TG Proxy — Официальное описание релиза v1.0.5

Подробный технический документ к релизу версии v1.0.5 для публикации в репозитории и на странице релизов GitHub.

## 1. Подлинность сборки и контрольные отпечатки SHA-256

Для защиты пользователей от несанкционированных модификаций, внедрения постороннего кода и переподписанных сторонних сборщиков в релизе v1.0.5 внедрена обновленная система встроенной проверки цифровой подписи (SignatureVerifier).

### Контрольные отпечатки SHA-256 файлов сборки (APK SHA-256 Checksums)
* **app-release.apk SHA-256**: `3B3D4B40472A9C45002C8C9C6A19079ADBB5F4DB08497920391B2EBA9B8D2E92`

Приложение выполняет автоматическую верификацию указанного отпечатка при каждом запуске. В случае выявления несоответствия цифровой подписи пользователю выводится предупреждение об использовании неофициальной сборки с предложением перехода к оригинальному репозиторию.

## 2. Полный список изменений и технических улучшений в версии v1.0.5

### Безопасность и проверка целостности APK
* **Мульти-хеширование и верификация через GitHub API**:
  Система автообновления (UpdateManager) теперь поддерживает считывание нескольких контрольных отпечатков SHA-256 из описания релиза. Это исключает ложные срабатывания защиты при одновременно опубликованных Release и Debug вариантах сборки.
* **Автономная офлайн-проверка подлинности (Offline-Safe Verification)**:
  Проверка ключа подписи работает локально на устройстве без обязательного наличия интернет-соединения при старте приложения.
* **Предупреждение о сторонних модификациях (UnofficialBuildDialog)**:
  Разработан специальный модальный диалог безопасности с официальным отказом от ответственности авторов за сохранность данных при использовании модифицированных сторонних клиентов.

### Сетевой стек и оптимизация производительности
* **Оптимизация пропускной способности (High Throughput Download Buffer)**:
  Размер сетевого буфера чтения/записи сокетов увеличен до базовых 128 KB по умолчанию и расширен до 2 MB (2 097 152 байт) в максимальном режиме, что обеспечивает мгновенный стриминг 4K-видео и параллельную загрузку тяжелых медиафайлов Telegram.
* **Сквозное отключение задержек алгоритма Нагла (TCP_NODELAY)**:
  Применение опции TCP_NODELAY для всех соединений устраняет задержки отправки пакетов (40–200 мс) при выгрузке медиа и отправке мгновенных сообщений.
* **Гибкие профили скорости и пула сокетов (SpeedPresets)**:
  Реализованы точно настроенные режимы энергопотребления и производительности:
  * Режим Турбо: максимальный пул из 16 горячих сокетов на каждый DataCenter (DC) и гигантский буфер 2 MB (2 097 152 байт).
  * Режим Баланс: оптимальный пул из 8 горячих сокетов на DC и увеличенный буфер 256 KB (262 144 байт).
  * Режим Эко: экономичный пул из 2 сокетов на DC и компактный буфер 32 KB (32 768 байт).
* **Резервный Kotlin-движок (TgWsBridge Fallback)**:
  В случае недоступности или сбоя инициализации нативного C/Rust модуля проксирование автоматически переключается на встроенный движок TgWsBridge с сохранением пресетов и буферизации сокетов.

### Учет трафика и мониторинг
* **Двухуровневый счетчик (TrafficStats Fallback)**:
  Использование вызовов Linux-ядра Android (TrafficStats.getUidRxBytes / getUidTxBytes) для точного учета переданных байтов приложения.
* **Динамический перерасчет скорости**:
  Ежесекундное обновление показателей входящей и исходящей скорости (Б/с, КБ/с, МБ/с) на главном экране и в уведомлении сервиса.
* **Автоматический сброс точки отсчета (resetBaseline)**:
  При каждом запуске прокси-сервера счетчик трафика текущей сессии сбрасывается в 0 Б.

### Пользовательский интерфейс и UX
* **Эффекты размытия стекла (Glassmorphism)**:
  Интеграция системного размытия заднего плана (FLAG_BLUR_BEHIND, blurBehindRadius 55) для модальных окон и диалогов на устройствах под управлением Android 12+.
* **Подтверждение внешних ссылок (ExternalLinkConfirmDialog)**:
  Защитный диалог перед открытием внешних интернет-ресурсов для предотвращения случайных переходов.
* **Интерактивная плашка подлинности (OfficialSourceCard)**:
  Карточка подлинности вынесена в верхнюю часть экрана Настроек. Добавлено три компактные кнопки: Репозиторий, Релизы и Проверить хеш.
* **Диалог просмотра отпечатка подписи**:
  Возможность просмотра точного SHA-256 хешкода установленного APK и его копирования в буфер обмена в один клик.

### Интеграция с системой Android
* **Плитка быстрых настроек (Quick Settings Tile)**:
  Переключение состояния прокси-сервера в один клик из шторки уведомлений Android. Удержание плитки перенаправляет пользователя непосредственно в приложение.
* **Служба первого плана (ProxyForegroundService)**:
  Оптимизировано удержание процесса в памяти и обновление статуса в уведомлении Android.

## 3. Инструкция по самостоятельной проверке SHA-256 отпечатка APK

Вы можете самостоятельно проверить целостность скачанного APK-файла перед установкой.

### Вариант 1: Через утилиту keytool (входит в состав Java JDK / Android Studio)
```bash
keytool -printcert -jarfile Mirrly-TG-Proxy-v1.0.5.apk
```
В выведенной информации найдите строку SHA256. Она должна совпадать со значением:
`97:73:5C:0A:20:70:7F:D4:E4:BD:93:A2:D8:48:CA:91:9A:C5:40:45:4A:62:16:E8:CC:7D:43:4F:1F:9F:0A:96`

### Вариант 2: Через apksigner (Android SDK Build-Tools)
```bash
apksigner verify --print-certs Mirrly-TG-Proxy-v1.0.5.apk
```
