# Project Guidelines & Release Rules (Mirrly TG Proxy)

## 1. GitHub Release Notes Format & Verification Rule
При публикации релиза на GitHub для проекта Mirrly TG Proxy **ОБЯЗАТЕЛЬНО**:
1. **Первые две строчки релиза (Changelog Summary Preview)**: Первые 1–2 предложения релиза (после главного заголовка `#`) ДОЛЖНЫ содержать краткую выжимку ключевых изменений без использования спецсимволов заголовков (`#`). Данная выжимка автоматически извлекается парсером `UpdateChecker` и выводится в интерактивных уведомлениях Android (Rich Update Notifications).
2. **Контрольные отпечатки SHA-256**: Указывать в описании релиза контрольные отпечатки SHA-256 файлов `app-release.apk`, `app-debug.apk` и ключа подписи (Keystore SHA-256).

Пример структуры начала релиза:
```markdown
# Mirrly TG Proxy — Релиз v1.0.5.1
В v1.0.5.1 реализована повышенная скорость буферизации до 2 МБ, защита от заторов сети и поддержка интерактивных уведомлений.

---
```
