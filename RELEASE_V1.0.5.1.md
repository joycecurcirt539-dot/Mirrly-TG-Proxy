## 1. Подлинность сборки и контрольные отпечатки SHA-256

Для обеспечения безопасности пользователей при использовании приложения Mirrly TG Proxy в версии v1.0.5.1 внедрена встроенная система проверки цифровой подписи (SignatureVerifier) и C++ NDK защиты.

### Контрольные отпечатки SHA-256 файлов сборки (APK SHA-256 Checksums)
* **app-release.apk SHA-256**: `1BE5C7D789CB1CE2A3C327F46B118651E3990581C4B788529AF074CD9E180446`

Приложение выполняет автоматическую верификацию указанного отпечатка при каждом запуске. В случае выявления несоответствия цифровой подписи пользователю выводится предупреждение об использовании неофициальной сборки с предложением перехода к оригинальному репозиторию.

## 2. Полный список изменений и технических улучшений в версии v1.0.5.1

### Безопасность и проверка целостности APK
* **Нативная верификация подписи в C++ NDK (mirrly_sec)**:
  Проверка отпечатков цифровой подписи перенесена на уровень нативного C++ кода с шифрованием эталонного SHA-256 ключа подписи (XOR 0x5A) для защиты от модификаций Smali.
* **Мульти-хеширование и верификация через GitHub API**:
  Система автообновления (UpdateManager) поддерживает считывание нескольких контрольных отпечатков SHA-256 из описания релиза для корректной поддержки Release и Debug сборок.
* **Предупреждение о сторонних модификациях (UnofficialBuildDialog)**:
  Специальный диалог безопасности с официальным отказом от ответственности авторов за сохранность данных при использовании модифицированных сторонних клиентов.

### Сетевой стек и оптимизация производительности
* **Оптимизация пропускной способности (High Throughput Download Buffer)**:
  Размер сетевого буфера сокетов оптимизирован до 2 MB в режиме Турбо для мгновенного стриминга 4K-видео и параллельной загрузки тяжелых медиафайлов Telegram.
* **Сквозное отключение задержек алгоритма Нагла (TCP_NODELAY)**:
  Применение опции TCP_NODELAY устраняет задержки отправки пакетов (40–200 мс).

## 3. Инструкция по самостоятельной проверке SHA-256 отпечатка APK

### Вариант 1: Через утилиту keytool (из состава Java JDK / Android Studio)
```bash
keytool -printcert -jarfile Mirrly-TG-Proxy-v1.0.5.1.apk
```
В выведенной информации найдите строку SHA256. Она должна совпадать со значением:
`97:73:5C:0A:20:70:7F:D4:E4:BD:93:A2:D8:48:CA:91:9A:C5:40:45:4A:62:16:E8:CC:7D:43:4F:1F:9F:0A:96`

### Вариант 2: Через apksigner (Android SDK Build-Tools)
```bash
apksigner verify --print-certs Mirrly-TG-Proxy-v1.0.5.1.apk
```
