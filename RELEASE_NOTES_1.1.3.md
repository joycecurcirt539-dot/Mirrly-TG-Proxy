## 2. Назначение установочных пакетов (APK)
* **app-universal-release.apk**: Универсальная сборка. Содержит нативные библиотеки под все архитектуры (ARM64, ARMv7, x86, x86_64). Гарантированно подходит для любого Android-устройства. Единый основной файл для автообновлений и публикации.
* **app-arm64-v8a-release.apk**: Сборка ARM64. Оптимизирована для большинства современных смартфонов и планшетов (64-битные процессоры ARM). Обладает наименьшим размером.
* **app-armeabi-v7a-release.apk**: Сборка ARMv7. Для 32-битных Android-устройств предыдущих поколений.
* **app-x86_64-release.apk**: Сборка x86_64. Для 64-битных эмуляторов Android (Android Studio, LDPlayer, BlueStacks) и устройств на процессорах Intel/AMD.
* **app-x86-release.apk**: Сборка x86. Для 32-битных эмуляторов Android x86.

## 3. Ключевые изменения

### Импорт воркеров через Deep Links в 1 клик
* **Поддержка системных ссылок `mirrly://worker`**:
  * Реализована бесшовная интеграция с протоколами `mirrly://worker?domain=...&name=...` и `https://mirrly.app/worker?...`.
  * При переходе по ссылке из любого мессенджера или браузера приложение автоматически открывает диалог подтверждения импорта.
  * Пользователь видит имя и домен узла с возможностью сразу активировать подключение.
* **Генерация глубоких ссылок при отправке**:
  * Кнопка «Поделиться воркером» автоматически формирует глубокую ссылку для моментального подключения друзьями (доступна только для пользовательских воркеров).

### Менеджер воркеров (Worker Manager)
* **Единый дизайн и выпадающая панель**:
  * Вкладка открывается плавным выездом сверху вниз прямо поверх живого космического фона (Cyber Energy Canvas) с эффектом прозрачного матового стекла.
  * Интерактивный бейдж активного воркера в шапке главного экрана прямо под переключателем `Mirrly SOCKS5`.
  * Быстрое переключение активного узла в 1 клик.
  * Разделение на **Официальный узел разработчика** (защищен от удаления и отправки) и **Личные воркеры**.
* **Ручной замер пинга и диагностика HTTP 429**:
  * Кнопка «Пинг» для безопасного ручного опроса узлов без фонового расхода суточных квот.
  * Отображение цветовой индикации задержки (зеленый / желтый / красный) и специального предупреждающего бейджа `429: Лимиты исчерпаны`.
  * Информационное окно с разъяснением суточных лимитов Cloudflare (100 000 запросов) и времени сброса (00:00 UTC).

### Сетевой стек и балансировка (Rust Core)
* **Скоростной балансировщик Anycast (Fast Race & Latency Balancer)**:
  * Внедрен параллельный замер задержки (RFC 8305 Happy Eyeballs) со ступенчатым стартом 25 мс и коротким таймаутом 450 мс.
  * Первый ответивший узел моментально назначается активным, исключая паузы при холодном старте.
  * Балансировщик сортирует домены по минимальному RTT и выполняет тихий замер 1 раз в 60 минут без перерасхода лимитов Cloudflare.
  * Таймаут переключения на следующий узел сокращен с 4.0 с до 600 мс.

### Пользовательский интерфейс и настройки
* **Интерактивные чипы на Главном экране**:
  * Добавлен компактный чип `Воркер: [Имя активного]` в заголовке и карточки в Настройках.
* **Интерактивная инструкция по Cloudflare Worker**:
  * Полноэкранная вкладка `CloudflareWorkerGuideScreen` с пошаговыми инструкциями для ПК и Смартфона.
